# manole-webchat

Painel de WebChat "Assistente Manole" (canal WWC da Weni / CX Platform).

- `demo/`: código-fonte do painel (`demo/src/webchat`) e a demo publicada na Vercel, que serve uma cópia da home da loja com o painel.
- `io/`: app VTEX IO `manole.webchat-assistant`, instalado na loja. O código do painel vem da demo: rode `sh io/scripts/sync-from-demo.sh` antes de `vtex publish`.

Veja `io/docs/README.md` para os detalhes do app.
